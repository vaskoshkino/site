# ТОЧКА — информационный лендинг о дезинсекции в Москве

Одностраничный демонстрационный сайт на русском языке. Это **макет**, а не действующая форма заказа услуг: заявки не собираются, онлайн-записи нет. Кнопки ведут к разделам этой страницы. В интерфейсе нет вымышленных телефона, адреса, цен, лицензий, отзывов и гарантий.

## Файлы

- `index.html` — семантическая структура, метатеги и контент.
- `css/style.css` — адаптивная вёрстка, состояния фокуса и reduced motion.
- `img/mark.svg` — собственная SVG-иконка; иллюстрация в первом экране встроена в HTML.

Внешних зависимостей, CDN, шрифтов и JavaScript нет. Используются относительные пути, включая размещение на GitHub Pages по адресу вида `/site/`.

## Запуск

Откройте `index.html` в браузере либо запустите любой локальный статический сервер из корня репозитория. Для размещения достаточно опубликовать содержимое репозитория как статический сайт.

## Перед публикацией рабочего сайта

Владелец должен предоставить и подтвердить **реальные контакты, юридические сведения (если требуются), условия работы, цены и порядок обработки заявок**. Только после этого можно добавлять контактные CTA, форму с реальным серверным обработчиком и политику обработки данных. Canonical URL и Open Graph URL указывают на текущий адрес GitHub Pages. При переезде на собственный домен обновите их; при наличии утверждённой обложки добавьте Open Graph image. Текущие материалы не обещают конкретный результат обработки или безопасность препаратов; инструкции для конкретного случая должен предоставить исполнитель.
