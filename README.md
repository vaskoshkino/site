# МСК Дез — информационный лендинг

Русскоязычный статический сайт о дезинсекции в Москве для бренда «МСК Дез». Сейчас размещён на GitHub Pages по адресу `https://vaskoshkino.github.io/site/`; переход на mskdez.ru возможен после настройки DNS. Это информационная версия: заявки и запись не принимаются, контакты будут опубликованы только после подтверждения владельцем. Сайт не заявляет неподтверждённых цен, гарантий, рейтингов, адреса или телефона.

## Файлы

- `index.html` — HTML5, SEO/Open Graph, WebPage JSON-LD и контент.
- `css/style.css` — адаптивная вёрстка, фокус, reduced motion.
- `js/menu.js` — меню с aria-expanded, Escape, закрытием вне меню/по ссылке и при переходе на desktop.
- `img/mark.svg` — локальная иконка.
- `sitemap.xml` — карта текущего URL; `robots.txt` — заготовка для размещения в корне домена.

Без внешних CDN, шрифтов, фотографий, аналитики и зависимостей. Все CTA ведут на разделы страницы. Для запуска откройте `index.html` или запустите локальный статический сервер из корня репозитория. Вложенный путь /site/ поддерживается относительными путями ресурсов.

## Перед публикацией как действующего сервиса

Владелец подтверждает реальные контакты, юридические сведения, условия работы и цены. Для формы потребуется действующий серверный обработчик и политика обработки данных. Сейчас `/site/robots.txt` не управляет сканированием всего домена github.io: поисковики запрашивают robots.txt в корне домена. Карту `/site/sitemap.xml` можно предоставить поисковым системам отдельно. При переносе на собственный домен обновите canonical, og:url, JSON-LD url, robots.txt, sitemap.xml и настройки GitHub Pages. Общие советы на сайте не заменяют инструкции по конкретному средству и помещению.
